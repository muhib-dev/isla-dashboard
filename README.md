# ISLA School Hub (prototype)

A clickable prototype of a dashboard for ISLA staff and school administrators. It covers school profiles, Job Portal, a knowledge assistant, regional analytics, billing, and the ISLA Store.

It uses sample data, and every school and person in it is fictional. Use the menu in the top right to switch between the **School admin** view (Al-Noor Academy) and the **ISLA staff** view.

## Run

```bash
npm install
npm run dev            # http://localhost:3000
```

## Stack

- Next.js 16 App Router with Cache Components (`'use cache'`, `cacheLife`, `cacheTag`, `updateTag`) and Partial Prerendering
- shadcn/ui (Radix, Nova), Tailwind v4, Recharts
- Zod contracts shared by the mock data and the real API

## Structure

```
src/
  app/(dashboard)/     routes (thin: session + composition)
  features/<name>/     schema.ts · queries.ts · actions.ts · lib.ts · components/
  server/              session, repository interfaces, mock + http adapters
  components/          layout, shared bits, shadcn ui
  config/              env (validated), external links
  data/                sample JSON (generated by scripts/generate-mock-data.mjs)
```

## Moving to the real API

Set `DATA_SOURCE=http` and `ISLA_API_URL`. See [docs/API_MIGRATION.md](docs/API_MIGRATION.md) for the endpoint contract.
